# Styr

Styr runs your Claude Code agents: start them from a browser or a webhook, watch what they do,
approve what matters from your phone, chain them into pipelines, and keep every decision on
your own box. Free, self-hosted, one binary.

Status: pre-alpha, under construction. See `docs/specs/` for the design and
`docs/superpowers/plans/` for the build plan.
