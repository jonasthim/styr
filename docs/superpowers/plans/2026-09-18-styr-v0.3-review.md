# Styr v0.3 "Review" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. One card per worktree; the orchestrator merges.

**Goal:** Trust the output. Every session on a worktree-enabled workspace runs in its own git
worktree; the session view shows the real diff, inline comments become the next prompt, the
work can be committed or turned into a PR from the UI, every turn leaves a checkpoint to rewind
to, and a plan-mode session shows its plan as a checklist you approve.

**Architecture:** New `internal/gitops` (worktrees, diffs, checkpoints, commit, push, PR via
`gh`). Sessions create a worktree at start when the workspace opts in, store its path, run the
CLI with cwd = worktree, and checkpoint after each result. New review endpoints under
`/sessions/{id}`. Frontend: DiffView with inline comments, review composer, commit and PR
dialogs, checkpoint list with rewind, plan card, diff badges.

**Constraints:** as v0.1/v0.2 plans. Styr manages worktrees itself (not the CLI's `--worktree`)
so it knows the path; branch names `styr/<session short id>-<slug>`; worktrees live under
`<workspace path>/.styr/worktrees/<session id>` and that directory is git-ignored via
`.git/info/exclude`. `gh` is optional: PR creation reports "gh not installed or not
authenticated" cleanly. Never force-push. Never touch the workspace's main checkout beyond
`git worktree` commands and reading refs.

## Data model (migration `00005_review.sql`)

```sql
ALTER TABLE workspaces ADD COLUMN base_branch TEXT NOT NULL DEFAULT '';        -- '' = detect (HEAD's branch at worktree creation)
ALTER TABLE workspaces ADD COLUMN auto_checkpoint INTEGER NOT NULL DEFAULT 1;
ALTER TABLE sessions ADD COLUMN branch TEXT NOT NULL DEFAULT '';
ALTER TABLE sessions ADD COLUMN base_ref TEXT NOT NULL DEFAULT '';             -- commit the worktree started from
ALTER TABLE sessions ADD COLUMN diff_add INTEGER NOT NULL DEFAULT 0;           -- already exists? keep if present
ALTER TABLE sessions ADD COLUMN diff_del INTEGER NOT NULL DEFAULT 0;
CREATE TABLE review_comments (
  id TEXT PRIMARY KEY, session_id TEXT NOT NULL REFERENCES sessions(id) ON DELETE CASCADE, path TEXT NOT NULL,
  line INTEGER NOT NULL, side TEXT NOT NULL CHECK (side IN ('old','new')), body TEXT NOT NULL,
  author_id TEXT NOT NULL, created_at TEXT NOT NULL, sent_at TEXT);
CREATE TABLE checkpoints (
  id TEXT PRIMARY KEY, session_id TEXT NOT NULL REFERENCES sessions(id) ON DELETE CASCADE, commit_sha TEXT NOT NULL,
  turn INTEGER NOT NULL, summary TEXT NOT NULL DEFAULT '', created_at TEXT NOT NULL);
CREATE INDEX checkpoints_session_idx ON checkpoints(session_id, created_at DESC);
```
(`diff_add`/`diff_del` exist since 00001; skip those ALTERs.)

## gitops package (`internal/gitops`)

```go
type Repo struct{ Path string }                         // the workspace checkout
func (r Repo) CurrentBranch(ctx) (string, error)
func (r Repo) AddWorktree(ctx, dir, branch, base string) error   // git worktree add -b branch dir base; excludes .styr/ in .git/info/exclude
func (r Repo) RemoveWorktree(ctx, dir string, deleteBranch bool) error
type Worktree struct{ Path, Branch, BaseRef string }
func (w Worktree) Status(ctx) (Status, error)           // dirty files with X/Y codes
func (w Worktree) DiffSummary(ctx) (Summary, error)     // vs BaseRef, includes uncommitted: []FileChange{Path, OldPath, Status A/M/D/R, Add, Del}, TotalAdd, TotalDel
func (w Worktree) FileDiff(ctx, path string) (FileDiff, error) // unified diff hunks vs BaseRef incl. working tree; binary flagged; max 2 MB
func (w Worktree) Checkpoint(ctx, message string) (sha string, dirty bool, err error) // git add -A && commit --no-verify -q; author "Styr <styr@local>"; returns dirty=false when nothing to commit
func (w Worktree) Log(ctx, since string) ([]Commit, error)
func (w Worktree) Rewind(ctx, sha string) error         // git reset --hard sha (only to a sha on this branch)
func (w Worktree) Commit(ctx, message string, author Author) (sha string, err error) // squash? no: plain commit of the working tree on top; if there are checkpoint commits, first `git reset --soft base` to fold them into one commit, then commit
func (w Worktree) Push(ctx) error                       // git push -u origin branch (no force)
func (w Worktree) CreatePR(ctx, title, body, base string) (url string, err error) // gh pr create --head branch --base base; ErrGHUnavailable when gh missing/unauthenticated
func (w Worktree) Patch(ctx) ([]byte, error)            // git diff base...HEAD plus working tree, for download
```

## API (`/api/v1/sessions/{id}/…`, owner or admin)

```
GET  diff                      → {base_ref, branch, files: [FileChange], total_add, total_del, dirty}
GET  diff/file?path=           → FileDiff {path, old_path, status, binary, hunks: [{old_start, old_lines, new_start, new_lines, lines: [{type: ctx|add|del, old_no, new_no, text}]}]}
GET  comments ; POST comments {path, line, side, body} → 201 ; DELETE comments/{cid}
POST review                    → sends every unsent comment as one user message (format below), marks them sent, 202
POST commit {message}          → {sha}
POST pr {title, body, base?}   → {url}   ; 409 code gh_unavailable with a message
GET  checkpoints               → [{id, commit_sha, turn, summary, created_at}]
POST rewind {checkpoint_id}    → 202 (refuses while running/waiting)
POST discard                   → 204: removes the worktree and branch, session closed; refuses while running
GET  patch                     → text/x-diff download
```

Review message format sent to the CLI:
```
Review comments on your changes (address each, then summarise what you changed):
- src/auth.go:42 (new): <body>
- README.md:10 (old): <body>
```

## Plan approval

Sessions created with profile mode `plan` (or `/plan` from the composer, which switches the
session to a plan-mode resume like the model switch) produce an `ExitPlanMode` permission
request whose input carries the plan markdown. Styr renders it as a Plan card (markdown with
checkboxes editable), "Approve plan" = allow, "Request changes" = deny with the typed comment.
T41 spikes the exact shape in `-p` mode and whether the CLI then continues in default mode
after approval or needs a resume with `--permission-mode default` (if so, Styr does that
automatically: approve → SwitchMode(default) → resume).

## Frontend

- Session Changes tab becomes **Review**: file list with A/M/D chips and +/−, DiffView per file
  (side-by-side on ≥ 1100 px, unified below; syntax colouring via a light tokenizer, no heavy
  highlighter), click a line number → inline comment box; comments listed in a right rail;
  "Send review" composes the next prompt; badge on the tab with unsent count.
- Header actions: **Commit** (dialog with message, default from the session title), **Open
  PR** (title, body prefilled from the last result text, base branch), **Checkpoints** (popover
  list with "Rewind to here" and confirm), **Discard changes** (danger, confirm).
- Sessions list: diff badge `+42 −18` from the session row (updated by `session.stats`).
- Inbox: a plan awaiting approval is a Needs-you item (kind `plan`), with the plan card inline.
- Plan card in the session view above the composer while pending.
